# Example 2: Solution Evaluation

## Scenario

A project management SaaS product wants to improve task completion rates.

The team has three possible solutions:

1. Add AI-generated task summaries.
2. Simplify the task creation workflow.
3. Create guided onboarding for new users.

---

## User Input

Problem:

New users create fewer tasks than expected after signup.

Evidence:

- Analytics show a 40% drop-off after the first project creation step.
- Interviews show users are unsure what information to add.
- Support tickets mention confusion during setup.

---

## Candidate Solutions

### Solution A

AI-generated task summaries.

Expected outcome:

Users understand tasks better.

---

### Solution B

Simplify task creation workflow.

Expected outcome:

Users complete task creation more easily.

---

### Solution C

Guided onboarding.

Expected outcome:

Users understand how to create and organise projects.

---

# PDR Analysis

## Problem-Solution Fit

### Solution A

Fit:

Medium.

The solution may help users understand existing tasks but does not directly address task creation friction.

---

### Solution B

Fit:

High.

Evidence suggests users struggle during task creation.

---

### Solution C

Fit:

Medium-high.

Could reduce confusion, but may not solve workflow complexity.

---

## Constraints

Engineering estimates:

Solution A:
6 weeks

Solution B:
3 weeks

Solution C:
4 weeks

---

## Impact and Effort

| Solution            | Impact | Effort | Confidence |
| ------------------- | ------ | ------ | ---------- |
| AI summaries        | Medium | High   | Low        |
| Simplified workflow | High   | Medium | High       |
| Guided onboarding   | Medium | Medium | Medium     |

---

## Recommendation

Prioritise Solution B:

Simplify task creation workflow.

Reason:

- Strongest connection to identified problem.
- Supported by behavioural and qualitative evidence.
- Lower effort than alternatives.
- Higher confidence in expected impact.

---

## Solution Hypothesis

If we simplify task creation, new users will complete project setup more successfully, improving activation.

---

## Recommended Next Action

Create a prototype of the simplified workflow and validate whether users complete task creation more successfully.

---

## Human Validation Required

The team should validate the recommendation against technical constraints, roadmap priorities, and stakeholder goals before implementation.
